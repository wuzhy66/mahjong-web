# 提示 AI

提示选项为简单、中等、困难和 Astra-0，默认选中 Astra-0。简单对应 bc-mortal-v4-0-1，中等对应 r1-4，困难对应 historical297；对手难度仍为原来的三档。

Astra-0 固定集成 r1-12 / r1-14 / r1-17：三个模型分别在合法动作上做 softmax，概率相加后除以 3，再按最高分推荐。不是 logits 求和，也不是逐动作取最大概率。单模型采用 argmax 策略对应的概率分布。

三个集成成员模型随仓库放在 `server/models/`，不单独作为提示选项；加载时严格校验 SHA256。模型只在后台执行。提示覆盖出牌、吃碰杠胡及过，不替玩家执行。
